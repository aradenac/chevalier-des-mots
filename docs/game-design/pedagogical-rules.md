# Règles pédagogiques

Le jeu suit quelques règles simples pour rester utile à un enfant.

## Règle 1 : montrer la bonne cible

Chaque niveau doit contenir des mots qu’il faut trancher.
La cible doit être identifiable à partir de la consigne.

## Règle 2 : montrer des distracteurs crédibles

Les mots non cibles doivent ressembler au contexte du niveau.
Ils servent à faire travailler le tri.

Exemple :

- cible : `mange`
- distracteur : `mangé`

## Règle 3 : corriger vite

Le feedback doit arriver immédiatement après l’action.
La correction peut être courte, mais elle doit être claire.

## Règle 4 : éviter la punition dure

Une erreur ne doit pas interrompre l’apprentissage.
On préfère :

- un message bref
- un son léger
- une reprise rapide

## Règle 5 : conserver la lisibilité

La difficulté doit augmenter sans casser la compréhension.
Le joueur doit toujours savoir :

- quoi faire
- pourquoi il a réussi ou échoué
