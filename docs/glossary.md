# Glossaire

- `Feature` / `feat` : intention produit de haut niveau.
- `Requirement` / `req` : exigence vérifiable.
- `Design` / `dsn` : décision d'architecture ou de conception.
- `Implementation` / `impl` : code qui réalise une exigence.
- `Unit test` / `utest` : preuve automatique de comportement.
- `User manual` / `uman` : documentation orientée joueur.
- `Operation manual` / `oman` : documentation orientée maintenance.
- `OpenFastTrace` : outil CLI de traçabilité.
- `file://` : consultation locale sans serveur HTTP.
