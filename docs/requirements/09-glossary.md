# GLOSSARY

- `NEED` : besoin de haut niveau exprimé côté utilisateur, enfant ou mainteneur.
- `STKREQ` : exigence parties prenantes.
- `SYSREQ` : exigence système ou produit visible.
- `SWREQ` : exigence logicielle ou architecturale.
- `VERREQ` : exigence de vérification.
- `impl` : preuve dans le code.
- `utest` : test unitaire.
- `itest` : test d'intégration.
- `test result` : résultat produit par une commande de test ou de build.
- `evidence` : élément de preuve lisible dans le dépôt.
- `traceability` : capacité à relier besoin, exigence, code, test et résultat.
- `coverage` : état de couverture d'un artefact par ses éléments descendants.

Le glossaire n'ajoute pas de comportement. Il sert uniquement à lire le référentiel d'exigences sans ambiguïté.
