# Exigences des niveaux

Cette page décrit les exigences des 20 niveaux.
Elle reste lisible par un humain et exploitable par un LLM.

## Exigence portefeuille

`req~cdm.level-portfolio~1`

Le jeu doit fournir 20 niveaux thématiques stables, chacun avec un objectif pédagogique, des cibles, des distracteurs et un seuil d'étoiles.

Needs: dsn, utest, uman

## Exigences par niveau

| Niv. | Exigence |
| --- | --- |
| 1 | Les mots mal écrits doivent montrer des formes orthographiques courantes et leurs corrections. |
| 2 | Les lettres en trop doivent isoler une lettre ajoutée par erreur. |
| 3 | Les lettres manquantes doivent présenter des mots incomplets. |
| 4 | Les accents doivent tester les accents absents ou incorrects. |
| 5 | Les noms communs doivent rester distinguables des autres natures. |
| 6 | Les verbes simples doivent rester reconnaissables comme actions. |
| 7 | Les adjectifs doivent qualifier un nom sans ambiguïté. |
| 8 | Les déterminants doivent être visibles devant un nom. |
| 9 | Les pronoms personnels doivent inclure je, tu, il, nous et similaires. |
| 10 | Les adverbes doivent préciser l'action ou le temps de manière claire. |
| 11 | Les prépositions doivent introduire un complément. |
| 12 | Les conjonctions doivent relier des mots ou des propositions. |
| 13 | L'infinitif doit se distinguer d'une forme conjuguée. |
| 14 | Le verbe conjugué doit être associé à un sujet. |
| 15 | Le présent doit être distingué du futur et du passé composé. |
| 16 | Le futur doit être distingué du présent. |
| 17 | Le passé composé doit être identifiable avec son auxiliaire. |
| 18 | Les accords sujet-verbe doivent être visiblement faux ou corrects. |
| 19 | Les homophones doivent faire apparaître la bonne forme dans la phrase. |
| 20 | Le défi final doit mélanger plusieurs erreurs déjà rencontrées. |

## Critères de contrôle

- chaque niveau a un thème unique;
- chaque niveau a au moins une cible et un distracteur;
- les corrections sont courtes et lisibles;
- la montée de difficulté reste progressive;
- les 20 niveaux restent stables tant que le gameplay n'est pas modifié.
