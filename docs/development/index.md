# Développement

Cette partie explique comment travailler sur le dépôt sans casser les spécifications.

## Ce que le mainteneur doit garder en tête

- le jeu doit rester jouable;
- la documentation doit rester versionnée;
- la traçabilité doit rester auditable;
- les changements doivent rester petits.
