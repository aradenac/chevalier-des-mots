# ADR-0003 - Traçabilité OpenFastTrace

OpenFastTrace devient l'outil officiel de validation de traçabilité du projet.

## Décision

Le dépôt doit utiliser des spécifications versionnées en Markdown et les relier avec OpenFastTrace.

## Conséquences

- la traçabilité devient auditée;
- les exigences doivent rester stables;
- les interfaces, tests et guides doivent rester reliés;
- aucun validateur maison ne doit être ajouté.
