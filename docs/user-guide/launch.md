# Lancement

## Développement

Pour lancer le jeu en mode développement :

```bash
npm install
npm run dev
```

Le serveur Vite écoute sur `127.0.0.1`.

## Version build

Pour produire une version statique :

```bash
npm run build
```

Le résultat est placé dans `dist/`.

## Vérification

Le build doit s’exécuter sans erreur avant diffusion.
