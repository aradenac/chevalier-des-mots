# Notice utilisateur

Cette notice explique comment jouer sans lire le code.

## Ce que l'utilisateur doit savoir

- lancer le jeu;
- choisir un niveau;
- utiliser le clavier, le tactile ou la manette;
- comprendre les retours;
- diagnostiquer un problème de son ou de voix.
