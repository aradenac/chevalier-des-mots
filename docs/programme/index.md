# Référence pédagogique — Programme scolaire CE1

> Document informatif destiné à cadrer le contenu pédagogique du jeu **Chevalier des mots**.  
> Ce document n’est pas une spécification produit et ne constitue pas une exigence traçable.

## Cadre général

Le CE1 correspond à la deuxième année du **cycle 2** de l’école élémentaire française, aussi appelé cycle des apprentissages fondamentaux.  
Le cycle 2 comprend :

- CP ;
- CE1 ;
- CE2.

Le CE1 est une année de consolidation : l’élève automatise la lecture, renforce l’écriture, structure ses premiers apprentissages grammaticaux et développe ses compétences de calcul, d’expression orale, de compréhension et de raisonnement.

## Français

Le français est le domaine central pour un jeu comme **Chevalier des mots**, car il touche directement la lecture, l’orthographe, le vocabulaire et la compréhension.

### Lecture et compréhension

En CE1, l’élève consolide le décodage appris au CP et progresse vers une lecture plus fluide.

Les objectifs généraux sont notamment :

- lire des mots nouveaux en s’appuyant sur les correspondances entre lettres et sons ;
- lire à voix haute avec davantage de fluidité ;
- comprendre des textes courts ;
- identifier les personnages, les lieux, les actions et les événements principaux ;
- reformuler oralement ce qui a été lu ;
- respecter progressivement la ponctuation ;
- lire des textes narratifs, informatifs ou prescriptifs simples.

Un repère courant de fin de CE1 est une lecture fluide d’environ **70 mots correctement lus par minute**.

### Écriture

L’élève de CE1 renforce l’écriture manuscrite, la copie et la production de phrases.

Les apprentissages portent notamment sur :

- l’écriture cursive ;
- les majuscules cursives ;
- la copie de phrases et de textes courts ;
- la correction des erreurs de copie ;
- la dictée de mots, de groupes de mots et de phrases ;
- la production de phrases simples ;
- la rédaction de petits textes cohérents.

En fin de CE1, l’élève doit progressivement pouvoir produire un texte court d’environ **six à sept phrases**.

### Oral

L’élève apprend à mieux écouter, s’exprimer et participer à des échanges.

Les compétences travaillées sont notamment :

- écouter une consigne ou un court récit ;
- raconter un événement ;
- décrire une image ou une situation ;
- expliquer une réponse ;
- participer à un échange collectif ;
- utiliser un vocabulaire adapté ;
- respecter les tours de parole.

### Vocabulaire

Le CE1 développe fortement le lexique.

Les notions importantes sont notamment :

- les familles de mots ;
- les synonymes ;
- les contraires ;
- les mots génériques et les mots spécifiques ;
- les expressions courantes ;
- le sens propre et le sens figuré dans des cas simples ;
- les préfixes et suffixes simples ;
- l’usage progressif du dictionnaire ;
- la mémorisation de mots fréquents.

### Grammaire et orthographe

L’élève commence une étude plus explicite de la langue.

Les notions travaillées incluent notamment :

- la phrase simple ;
- la ponctuation ;
- les types de phrases : déclarative, interrogative, impérative ;
- la forme négative ;
- le nom commun ;
- le nom propre ;
- le déterminant ;
- l’adjectif ;
- le verbe ;
- le pronom personnel sujet ;
- le groupe nominal ;
- l’accord dans le groupe nominal ;
- l’accord entre le sujet et le verbe ;
- la conjugaison des verbes fréquents.

Les verbes particulièrement travaillés sont :

- être ;
- avoir ;
- les verbes du premier groupe.

Les temps abordés incluent notamment :

- le présent ;
- l’imparfait ;
- le futur ;
- le passé composé.

## Mathématiques

Les mathématiques ne sont pas le cœur direct de **Chevalier des mots**, mais elles peuvent inspirer des mécaniques de score, de progression, de séries, de niveaux ou de défis.

### Nombres et numération

En CE1, l’élève travaille les nombres jusqu’à **1 000**.

Il apprend à :

- lire les nombres ;
- écrire les nombres ;
- représenter les nombres ;
- comparer et ranger les nombres ;
- comprendre les unités, dizaines et centaines ;
- utiliser les signes `=`, `<` et `>` ;
- placer des nombres sur une droite graduée.

### Calcul

L’élève consolide l’addition, la soustraction et découvre plus solidement le sens de la multiplication.

Les apprentissages incluent :

- le calcul mental régulier ;
- les additions ;
- les soustractions ;
- les doubles ;
- les moitiés ;
- les compléments ;
- les premières tables de multiplication ;
- l’usage du symbole `×`.

### Résolution de problèmes

La résolution de problèmes est pratiquée très régulièrement.

L’élève apprend à :

- comprendre une situation ;
- repérer les informations utiles ;
- choisir une opération ;
- représenter un problème ;
- vérifier la cohérence du résultat.

### Grandeurs, mesures et géométrie

L’élève découvre ou consolide :

- les longueurs ;
- les masses ;
- la monnaie ;
- les figures simples : carré, rectangle, triangle, cercle ;
- les solides simples : cube, boule, cône, cylindre, pavé ;
- l’usage de la règle ;
- le vocabulaire spatial et géométrique.

## Langue vivante étrangère ou régionale

L’enseignement d’une langue vivante est centré sur l’oral.

L’élève apprend à :

- saluer ;
- se présenter ;
- dire son âge ;
- comprendre des consignes simples ;
- répéter des mots ou phrases courtes ;
- chanter des comptines ;
- découvrir des éléments culturels simples.

## Enseignements artistiques

Les enseignements artistiques comprennent principalement les arts plastiques et l’éducation musicale.

### Arts plastiques

L’élève expérimente :

- les formes ;
- les couleurs ;
- les matières ;
- les gestes ;
- les outils ;
- la représentation du réel ou de l’imaginaire.

### Éducation musicale

L’élève travaille :

- la voix ;
- le rythme ;
- l’écoute ;
- le chant collectif ;
- la comparaison de sons ou d’œuvres simples.

## Éducation physique et sportive

L’EPS développe la motricité, la coopération et le respect des règles.

L’élève apprend à :

- courir ;
- sauter ;
- lancer ;
- adapter ses déplacements ;
- coopérer ;
- s’opposer dans des jeux collectifs ;
- respecter des règles ;
- tenir différents rôles dans une activité.

## Questionner le monde

Ce domaine prépare progressivement les sciences, l’histoire et la géographie.

L’élève apprend à observer, décrire, comparer, classer et expérimenter.

Les thèmes abordés incluent notamment :

- la matière ;
- l’eau ;
- les objets ;
- le vivant ;
- le corps humain ;
- le temps ;
- les générations ;
- les modes de vie ;
- les espaces proches ;
- les cartes et plans simples.

## Enseignement moral et civique

En CE1, l’élève travaille particulièrement le respect d’autrui et la vie collective.

Les notions importantes sont notamment :

- le respect ;
- l’égalité ;
- la civilité ;
- l’empathie ;
- la solidarité ;
- les règles communes ;
- la prévention des violences ;
- la prévention du harcèlement ;
- les symboles de la République ;
- la devise « Liberté, Égalité, Fraternité » ;
- la laïcité comme liberté de conscience.

## Éducation à la vie affective et relationnelle

L’élève aborde progressivement :

- l’estime de soi ;
- le respect de son corps ;
- l’intimité ;
- les émotions ;
- l’amitié ;
- la confiance ;
- l’entraide ;
- les stéréotypes filles-garçons ;
- le respect des différences.

## Implications possibles pour Chevalier des mots

Le jeu peut s’appuyer prioritairement sur les compétences de français attendues en CE1.

### Compétences directement pertinentes

Le jeu peut renforcer :

- la reconnaissance visuelle des mots ;
- la lecture rapide de mots courts ;
- la distinction entre mots correctement et incorrectement orthographiés ;
- la mémorisation de mots fréquents ;
- l’identification d’erreurs simples ;
- l’attention portée aux lettres muettes ;
- l’attention portée aux accents ;
- l’attention portée aux accords simples ;
- la familiarisation avec les familles de mots ;
- la reconnaissance de synonymes ou de contraires simples.

### Types d’erreurs adaptés à un niveau CE1

Les erreurs proposées dans le jeu peuvent porter sur :

- lettres inversées ;
- lettres oubliées ;
- lettres ajoutées ;
- accents manquants ;
- confusion de sons proches ;
- confusion entre graphies proches ;
- erreurs sur des mots fréquents ;
- accords simples au pluriel ;
- accords simples masculin / féminin ;
- formes verbales très fréquentes.

Exemples de paires utilisables :

| Mot correct | Mot incorrect possible |
|---|---|
| maison | maisan |
| cheval | chevale |
| enfant | anfent |
| école | ecole |
| garçon | garcon |
| fille | file |
| pomme | pome |
| petit | peti |
| grande | grantde |
| les chats | les chat |

### Points de vigilance

Le jeu doit éviter :

- les mots trop rares ;
- les règles grammaticales trop avancées ;
- les exceptions orthographiques très abstraites ;
- les phrases longues sous contrainte de temps ;
- les sanctions trop punitives ;
- les ambiguïtés où plusieurs réponses pourraient sembler acceptables ;
- les erreurs qui nécessitent une connaissance non encore stabilisée au CE1.

### Orientation pédagogique générale

Pour un enfant de CE1, le jeu devrait privilégier :

- des mots courts et fréquents ;
- une difficulté progressive ;
- des consignes très simples ;
- une forte lisibilité visuelle ;
- une répétition espacée des mots ;
- un retour immédiat après l’action ;
- une valorisation de l’essai ;
- une distinction claire entre erreur d’orthographe et erreur de lecture ;
- une progression par familles de sons, familles de mots ou catégories grammaticales simples.
